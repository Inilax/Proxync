title: Roadmap
description: What is planned for Proxync next, as tracked in the project README.
---

The following work is planned:

- **Offline-First SQLite Migration** — replace the synchronous JSON state file with SQLite for safer, faster persistence.
- **`npx proxync` CLI companion** — a command-line interface companion to the desktop app.
- **LAN dashboard** — a richer dashboard for machines on your network.
- **AI traffic debugger** — assist with diagnosing traffic and errors.
- **HAR / Postman export** — export captured traffic in HAR format and Postman collections.
- **Native notifications** — desktop notifications for tunnel and traffic events.
- **Request/response mocking** — mock endpoints for offline development.

This list is maintained alongside the project; see the [Changelog](/docs/changelog) for what has shipped so far.
